About This Project

Electra was developed to address real challenges in conducting elections within educational institutions. The platform provides end-to-end digital voting infrastructure — from secure voter login through to automated result generation — all while maintaining data integrity and transparency.

Core Highlights

🔐 One Vote Per User: Prevents duplicate submissions at the system level.
📊 Auto Results: Vote tallies generated automatically on election close.
🛡️ Auth-First: Only verified voters can access the ballot system.

Overview

Electra is a secure electronic voting platform developed to modernize and simplify the voting process within educational institutions. The system ensures secure voter authentication, transparent vote collection, and accurate result generation.

By replacing paper-based methods with a digital-first approach, Electra dramatically reduces the time and effort needed to conduct elections while improving accuracy and trust in the process.

The Problem

  • 📋 Manual Counting: Traditional methods are time-consuming and error-prone.
  • 🔓 Security Gaps: Paper votes are susceptible to tampering and manipulation.
  • 🐌 Slow Results: Manual tallying delays the announcement of outcomes.

The Solution

A centralized digital platform where authorized voters securely cast ballots, election admins manage the process, and results are generated automatically — in real time.

Challenges & Learnings

Building a secure voting system surfaces unique challenges around trust, integrity, and user experience.

01

Designing a Secure Voting Process

Ensuring the entire vote lifecycle — from casting to storage — was resistant to tampering and unauthorized access.

02

Preventing Duplicate Voting

Implementing reliable one-vote-per-user enforcement at the system level to maintain election integrity.

03

Managing Election Data

Structuring vote records so they remain auditable and accurate without exposing individual voter privacy.

04

Creating an Intuitive UX

Designing an interface simple enough for all users regardless of technical ability, with zero voting errors.

05

Authentication Workflow Design

Understanding and implementing secure session management to ensure only verified voters access the ballot.
